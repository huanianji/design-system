# Web：共同基础与平台边界

当前合批公共图标与管理/创作任务见[组合使用](../combined-workflows.md)及[动态图标调用](../components-dynamic-icons.md)，实际本机结果与待验范围只维护在[合批记录](../packaged-status.md)。本页后续历史初查不覆盖当前资源状态。

当前输入批已提供[普通字段与六位验证码公共入口](../components-inputs.md)，现有备注实际消费；本机操作、候选窗待验与完整平台边界见[输入批记录](../packaged-status.md)。

先读 `runtime-status.md` 的实际记录，核对所使用的浏览器、Node 与运行入口。

已提供[共同设计源与 Web/Godot 消费](../shared-foundation.md)、[公共按钮／Tab／展开](../components-first-batch.md)、输入／验证码和动态图标。Web 实际读取生成 CSS 与运行数据，已有角色不另手写一份；未覆盖控件按任务补充。P1 历史探针不代表目标产品或业务接口验收，当前覆盖与实际入口以资源表为准。

后续实现需检查语义控件、键盘与触控、焦点、响应布局、长文案、输入法、减少动态效果和适用的媒体行为。依任务读取所需模式，不将共华年的管理布局作为所有 Web 产品模板。

细节与已有基准分叉时按[交互差异排查](../interaction-review.md)先查操作边界、CSS / 原生浏览器默认状态和真实输入路径，再看配对画面；共用 CSS 令牌不等于点击后状态已经一致。

目标项目已有框架、版本、包管理器和锁文件时沿用；P1 不替新项目预设前端框架。Web 页面在手机或桌面壳中打开，不自动代表原生平台支持。

2026-10-27 字体对照已完成本机范围，入口与边界见[字体验证](../packaged-status.md)。新项目不能只看 `document.fonts.check()` 或 CSS 字族声明：需核对实际加载文件 / 摘要、字重渲染、回退样本、组合字符、长内容和放大。系统回退可能改变字形和数字宽度，数据角色应实测等宽性；本轮检查台提供配套系统等宽字体对照，未统一替换所有正文。主字库读取失败诊断不代表正式产品故障恢复已实现；Windows、网络性能和完整输入法 / 读屏仍待对应验证。
