# 方向形成与延续：P1 方法初稿

新产品先确定用户、任务、内容、平台和使用场景，再讨论视觉。已有产品先读档案，用户未要求改版时延续已认可主题。

需要新方向时，以相同的关键内容和任务比较布局、阅读顺序、密度、素材、形状与动态关系。方向要有具体理由和可见决定，不以“高级、现代”或换一个颜色代替。

将共同的圆润字形、弹性回应、选择/焦点、动态图标及连续收展转成各方向中的具体做法。工作区、作品内容和品牌区域分别确定表达强度。各产品可以有不同主题；当前没有统一紫色或三栏要求。

记录每个候选的适用场景、取舍与待定项。用户已经明确的要求属于输入约束；AI 未经选择的方案继续是建议。需要可视化时比较日常操作和实际界面，标识登场不能代替界面方向比较。

P1 可产出设计简报与候选方向。最小品牌识别、令牌、主题和可复用组件尚未实现；实际实现任务应依据资源状态和项目现状另行安排，不伪装已有完整资产。
