这是雨伞设计的便携分发副本，规则、字体许可、公共实现、当前生成资源和精选视觉参照都在包内。完整历史截图归档、旧构建、系统缓存和个人路径不随包迁移。资源表中标为摘要的条目指向本页，不代表包含原始报告。

- 共同方向：A、分层留白、视觉对齐、字体角色、日常运动和中性浅深背景已确认；具体数值允许按产品与平台调整。
- Web / Godot：公共按钮、Tab、展开、普通输入、验证码与动态图标，以及管理／创作组合样张已在 macOS 验证；样例使用本地数据，不能冒称业务后端验收。
- Lumina：2026-10-28 独立原生工作区完成界面验收，覆盖排版、图标悬停底框、显隐／锁定及关键帧入口。示例只验证本地界面状态，没有接入正式产品、Windows D3D12 或 Spout。
- 首版重点是可安装、可复用、可跨会话接续；正式 Lumina 接入不属于当前任务。目标电脑运行条件必须重新探测。
- Windows／Linux 原生运行、输入法候选窗、完整读屏、真实服务与输出均须按目标环境取得证据；包内候选值与已有 Mac 记录不替代它们。

使用 `scripts/portable.py doctor` 检查这台电脑。Godot 示例先用 `prepare` 复制到新目录再导入，不能依赖历史源机器的引擎路径。
